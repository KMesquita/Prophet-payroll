# Prophet payroll
Sistema acadêmico de folha de pagamento para empresa fictícia com diferentes tipos de funcionários desenvolvido em Java.

## Sobre o projeto

O Prophet payroll é um projeto acadêmico desenvolvido durante
uma atividade da faculdade realizada em parceria
educacional com a Oracle.

O sistema tem como objetivo aplicar conceitos de
programação orientada a objetos no processamento
de salários de diferentes categorias de colaboradores.

## Funcionalidades

- Gerenciamento de diferentes tipos de colaboradores
- Processamento de salários conforme a categoria

## Tecnologias

- Java
- Programação Orientada a Objetos (POO)
